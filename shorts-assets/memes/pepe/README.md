## 사용할 때 참고

- 배치 규칙: 4:3 콘텐츠 영역(1080×810) 가운데에 정렬하고, 비율을 유지한 채 영역을 거의 꽉 채우도록 키웁니다(가로 1026px 또는 세로 770px 중 먼저 닿는 쪽까지, 약 95%). 남는 공간은 캡처 컷과 같은 방식의 블러필로 채웁니다.
- 250px 안팎의 저해상도 이미지는 이 크기로 키우면 3~4배 확대가 되어 선이 부드럽게 뭉개집니다. 선명도가 중요하면 더 큰 원본으로 교체하세요.
- `depressed-couch.jpg`는 원본에 있던 EXIF 메타데이터를 제거해 저장했습니다.
- 페페(Pepe the Frog)는 Matt Furie의 캐릭터입니다. 수익화 채널에 쓸 때는 각 플랫폼의 정책을 확인하세요.
