# 일반 키보드 vs 기계식 키보드: 16초 루프 구성안 (시안)

양식은 `LOOP_TEMPLATE.md`(스패너 vs 라쳇 영상)와 같습니다. 720×1280, 24fps, 16초 무한루프, 나레이션 없이 BGM과 효과음만 씁니다.
정지 화면 시안은 `mockups/`에 있습니다. `still_rest.jpg`는 둘 다 손을 뗀 상태, `still_mech_input.jpg`는 기계식이 입력되는 순간, `still_membrane_input.jpg`는 멤브레인이 입력되는 순간이고, `overview.jpg`는 이 세 장을 나란히 붙인 것입니다.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 제목(고정) | 일반 키보드와 / **기계식 키보드**의 차이 (기계식 키보드만 주황) |
| 위 패널 칩 | `일반 키보드 · 멤브레인` (회색) |
| 위 패널 문장 | 고무 돔을 **바닥까지 꾹** 눌러야 막이 닿아 입력돼요 |
| 아래 패널 칩 | `기계식 키보드` (주황) |
| 아래 패널 문장 | 키마다 **스프링 스위치**, 절반만 눌러도 입력돼요 |
| 카운터(왼쪽 아래) | 「입력 횟수」 + 주황 숫자 + "회". 접점이 닿는 순간 +1 |
| 효과 문구 | 위: "꾹!"(흰색), 아래: "딸깍!"(주황) |

## 3D 장면: 키 3개를 가운데에서 세로로 자른 단면

공통: 앞쪽 절반을 잘라낸 단면입니다. 가운데 키만 움직이고, 양옆 키는 화면 끝에 반쯤 걸치게 둡니다.
양옆 키는 "멤브레인은 고무판 한 장을 모든 키가 같이 쓰고, 기계식은 키마다 스위치가 따로 있다"는 차이를 보여주는 역할입니다.

### 위: 멤브레인
- 아래에서 위로 쌓인 순서: 철판 → 아래 필름 → 구멍 뚫린 간격 필름 → 위 필름 → 고무 돔 시트(모든 키가 이어진 한 장) → 위 케이스(가이드 기둥) → 키캡과 키캡 기둥
- 동작: 키캡이 고무 돔을 누르면 돔 벽이 옆으로 찌그러집니다. 돔 안쪽의 검은 카본 패드가 위 필름을 눌러 아래 필름에 닿는 순간 접점이 주황으로 빛나고 +1이 됩니다.
- 접점은 3.4mm를 누른 맨 바닥에서만 닿습니다. "바닥까지 꾹"이 이 부분입니다.

### 아래: 기계식(체리 MX 방식의 일반적인 스위치)
- PCB(기판) 위에 스위치 하우징(검정)이 있고 철판에 끼워져 있습니다. 하우징 안에는 주황 스템, 하늘색 스프링, 금색 금속 접점 2장이 들어 있습니다.
- 동작: 손을 떼고 있을 때는 스템 옆의 다리가 움직이는 금속판을 밀어 두 접점을 떼어 놓습니다. 약 2mm를 누르면 다리가 비켜나고 금속판이 튕겨 붙으면서 접점이 빛나고 "딸깍!"과 함께 +1이 됩니다.
- 움직이는 부품끼리는 충돌 계산으로 겹치지 않게 했습니다. 금속판 끝은 스템 다리 면을 따라 미끄러집니다.

## 누르는 속도: 정해주셔야 하는 부분

| 안 | 위(멤브레인) | 아래(기계식) | 16초 뒤 카운터 | 특징 |
|---|---|---|---|---|
| **A. 같은 박자** | 2초마다 끝까지(3.4mm) | 2초마다 끝까지(4mm), 2mm에서 먼저 입력 | 8회 : 8회 | 정확합니다. 다만 숫자 차이가 없어서 카운터 비교가 심심합니다. |
| **B. 반만 누르기** (시안에 쓴 방식) | 2초마다 끝까지 | 1초마다 2.6mm까지만 눌러 입력 | 8회 : 16회 | 라쳇 영상처럼 "2배"가 바로 보입니다. 다만 2배 빠르다는 것은 연출상 과장입니다. 실제로는 바닥까지 안 쳐도 되니 손가락이 덜 움직인다는 정도입니다. |

## 소리
- BGM: 기존 `loop_audio.py`의 120BPM 오리지널 곡을 그대로 씁니다.
- 효과음: 멤브레인은 둔탁한 "툭", 기계식은 짧고 높은 "딸깍"을 직접 합성합니다. 접점이 닿는 시각에 맞춥니다.

## 남은 작업 (확정 후)
1. 멤브레인 필름과 접점이 작게 보입니다. 필름 두께를 조금 과장하거나 접점 빛을 키워 더 잘 보이게 합니다.
2. A/B 중 고른 박자로 타이밍을 확정합니다.
3. 전체 렌더링(약 2~3분) → 효과음+BGM 합성 → 프레임 확인 → 화면 전환·루프 이음매 검사.

## 다른 선택지: 위 패널을 펜타그래프로 바꾸기
노트북 키보드처럼 키캡 아래에 X자 지지대(가위 구조)를 넣고, 작은 고무 돔과 필름은 그대로 둡니다.
입력 원리(돔 + 필름 접촉)는 멤브레인과 같아서, 내부 차이를 보여주는 데는 멤브레인이 더 직관적이라고 봅니다. 원하시면 이쪽으로 바꿀 수 있습니다.

## 확정 사항 (렌더링 완료)
- 박자: A안(같은 박자). 두 키 모두 2초마다 끝까지 누릅니다.
- 카운터: 입력 횟수 대신 「누른 깊이 ○.○mm」를 실시간으로 표시하고, 입력되는 순간 숫자가 튀어 오릅니다. 멤브레인은 3.6mm(바닥), 기계식은 2.0mm에서 입력됩니다.
- 멤브레인 필름은 화면에서 보이도록 실제보다 두껍게(장당 0.5mm) 그렸습니다.
- 결과물: `video/keyboard-loop-16s.mp4` (720×1280, 24fps, 16초, AAC 음성)
